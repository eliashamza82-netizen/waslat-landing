What you actually pay forمما تتكوّن تكلفة واتساب بيزنس API؟

Unlike the free WhatsApp app, the official Business API cost has two parts: (1) Meta's messaging fees, which depend on the message category and are set and updated by Meta, and (2) the platform subscription that gives you the inbox, team, templates and automation. Waslat bundles both into clear SAR plans. بخلاف تطبيق واتساب المجاني، تتكوّن تكلفة واتساب بيزنس API الرسمي من جزأين: (1) رسوم ميتا للرسائل، وتعتمد على تصنيف الرسالة وتُحدَّد وتُحدَّث من قِبَل ميتا، و(2) اشتراك المنصة الذي يمنحك صندوق الوارد والفريق والقوالب والأتمتة. وتجمع وصلات الجزأين في باقات واضحة بالريال السعودي.

Why the message type changes the priceلماذا يؤثر نوع الرسالة في السعر؟

  • Marketing — promotions, offers and re-engagement. Usually the highest rate.تسويقية — العروض والحملات وإعادة التفاعل. عادةً الأعلى سعراً.
  • Utility — order updates, confirmations, shipping and account notifications.خدمية (Utility) — تحديثات الطلبات والتأكيدات والشحن وإشعارات الحساب.

  • Use well-targeted broadcasts instead of mass, untargeted sends.استخدم رسائل جماعية مستهدفة بدل الإرسال العشوائي الواسع.
  • Automate with a chatbot to deflect repetitive questions.استخدم الشات بوت لتقليل الأسئلة المتكررة.

How much does WhatsApp Business API cost?كم تكلفة واتساب بيزنس API؟

Is WhatsApp Business API free?هل واتساب بيزنس API مجاني؟
